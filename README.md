## 📋 Sobre o Projeto

Este projeto foi desenvolvido durante o curso de **HTML5 e CSS3** do professor Gustavo Guanabara. O foco foi criar uma tela de login com visual moderno, aplicando técnicas avançadas de estilização com CSS.

**O que foi praticado:**
- Formulários e inputs estilizados com CSS
- Uso de imagens e ícones decorativos
- Posicionamento e alinhamento com Flexbox
- Design responsivo e moderno
